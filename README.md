# Фундаментальные алгоритмы. Лабораторная работа № 3

Десять отдельных программ на C99. Для каждой задачи весь код находится в одном файле `labNN.c`.

## Сборка

```sh
make
make check
make memcheck
```

`make check` запускает примеры для всех задач. `make memcheck` прогоняет их под Valgrind с проверкой утечек. На Debian, Ubuntu или WSL можно установить Valgrind командой `sudo apt install valgrind`.

Например, первую задачу можно собрать отдельно:

```sh
gcc -std=c99 -Wall -Wextra lab01.c -o /tmp/lab01
/tmp/lab01 31 4
```

Ответ `1F` означает, что десятичное 31 записывается как `1F` в системе с основанием 16. Именно это проверяет первый пример в `tests.sh`. Для остальных задач скрипт так же подаёт небольшой набор данных и ищет в выводе ожидаемую строку. `make memcheck` повторяет эти примеры через Valgrind.

## Запуск

| № | Команда | Ввод |
|---|---|---|
| 1 | `build/lab01 -255 4` | Число и показатель степени основания. Ответ `-FF`. |
| 2 | `build/lab02` | Первая строка `n k`, затем `n` строк вида `id HH:MM HH:MM`. |
| 3 | `build/lab03 FILE` | Любой файл. |
| 4 | `build/lab04 string` или `build/lab04` | Демонстрация строк или почтовый диалог. Первая строка адреса вида `город\|улица\|дом\|корпус\|квартира\|индекс`. |
| 5 | `build/lab05 INPUT TRACE` | В каждой строке файла `id имя фамилия группа оценка1 оценка2 оценка3 оценка4 оценка5`. |
| 6 | `build/lab06 STOP1 STOP2 ...` | В первой строке каждого файла `x y`. Запись вида `Bus 19.11.2026 09:00:00 19.11.2026 09:00:30 S`. Маркеры `S`, `I`, `F` обозначают начало, промежуточную остановку и конец. |
| 7 | `build/lab07 INPUT` | Запись вида `Ivanov Ivan - 10 05 1980 M 700`. |
| 8 | `build/lab08 INPUT` | Инструкции вида `Mult(x+1,x-1); Eval(2); Diff();`. |
| 9 | `build/lab09 FILE ' ' ','` | Текст UTF-8. Каждый разделитель передаётся отдельным аргументом. |
| 10 | `build/lab10 INPUT OUTPUT` | Одно выражение на строку, например `A(B(D),C)`. |

Интерактивные программы печатают список команд при запуске. Команды вводятся по одной на строку. Для выхода введи `quit`.

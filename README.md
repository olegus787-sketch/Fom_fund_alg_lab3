# Фундаментальные алгоритмы. Лабораторная работа № 3

Десять отдельных программ на C99. Для каждой задачи весь код находится в одном файле `labNN.c`.

## Сборка

```sh
make
make check
make memcheck
```

`make check` запускает примеры для всех задач. `make memcheck` прогоняет их под Valgrind с проверкой утечек. На Debian, Ubuntu или WSL можно установить Valgrind командой `sudo apt install valgrind`.

После `make` в корне появляются отдельные исполняемые файлы `lab1`–`lab10`. Первую задачу можно также собрать отдельно:

```sh
make lab1
./lab1 31 4
```

Ответ `1F` означает, что десятичное 31 записывается как `1F` в системе с основанием 16. Именно это проверяет первый пример в `tests.sh`. Для остальных задач скрипт так же подаёт небольшой набор данных и ищет в выводе ожидаемую строку. `make memcheck` повторяет эти примеры через Valgrind.

## Запуск

| № | Команда | Ввод |
|---|---|---|
| 1 | `./lab1 -255 4` | Число и показатель степени основания. Ответ `-FF`. |
| 2 | `./lab2` | Первая строка `n k`, затем `n` строк вида `id HH:MM HH:MM`. |
| 3 | `./lab3 FILE` | Любой файл. |
| 4 | `./lab4 string` или `./lab4` | Демонстрация строк или почтовый диалог. Первая строка адреса вида `город\|улица\|дом\|корпус\|квартира\|индекс`. |
| 5 | `./lab5 INPUT TRACE` | В каждой строке файла `id имя фамилия группа оценка1 оценка2 оценка3 оценка4 оценка5`. |
| 6 | `./lab6 STOP1 STOP2 ...` | В первой строке каждого файла `x y`. Запись вида `Bus 19.11.2026 09:00:00 19.11.2026 09:00:30 S`. Маркеры `S`, `I`, `F` обозначают начало, промежуточную остановку и конец. |
| 7 | `./lab7 INPUT` | Запись вида `Ivanov Ivan - 10 05 1980 M 700`. |
| 8 | `./lab8 INPUT` | Инструкции вида `Mult(x+1,x-1); Eval(2); Diff();`. |
| 9 | `./lab9 FILE ' ' ','` | Текст UTF-8. Каждый разделитель передаётся отдельным аргументом. |
| 10 | `./lab10 INPUT OUTPUT` | Одно выражение на строку, например `A(B(D),C)`. |

Интерактивные программы печатают список команд при запуске. Команды вводятся по одной на строку. Для выхода введи `quit`.
